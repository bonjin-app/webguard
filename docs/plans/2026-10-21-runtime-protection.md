# WebGuard 선택형 코드·런타임 보호

사용자 승인 범위: 웹 SDK의 난독화·실행 가드 보강과 공개 데모 반영. npm 게시와 Codex 설정 변경은 보류한다.

- CSS Modules의 빌드 식별자를 결정적으로 변환한다. Vite JS/CSS와 Next 서버·클라이언트가 같은 프로젝트 루트 기반 이름을 사용한다. 전역 CSS, 임의 DOM ID, 서버 언어 원본, 런타임 DOM 전체 변경은 제외한다.
- 실행 지연은 명시적 호출마다 한 번만 관찰한다. 보이는 페이지의 타이머 지연을 의심 신호로 기록하며 DevTools 열림을 단정하지 않는다. 반복 debugger, 무한 루프, 내비게이션·데이터 삭제를 사용하지 않는다.
- DOM 무결성은 명시적으로 선택한 작은 정적 light-DOM 영역만 관찰한다. 노드·바이트·선택자 수를 제한하고 불일치/오류 후 중지한다. 정상 변경 후 기준 갱신은 앱이 명시적으로 호출한다. 렌더링 전 없는 영역은 오류를 알리고 렌더링 후 수집한다.
- 두 실행 가드는 기본 OFF, 보고 우선이다. 선택적 페이지 안내는 화면 상호작용에 대한 대응이며 브라우저/서버 보안 경계가 아니다. 이벤트에 DOM 원문을 포함하지 않는다.
- 데모는 같은 자동 SDK를 재사용한다. 실제 DOM 변경·명시적 타이머 측정·현재 CSS 클래스를 표시한다. 공개 앱 자체 JS 난독화와 소스맵 제거를 유지한다.

검증: 엄격한 옵션 검증, 예산, 취소·갱신·파기·콜백 재진입 단위 테스트; 실제 Vite 클래스/스타일; 패키지 설치한 Next nonce CSP/SSR/hydration/지연 import; Chromium·Firefox·WebKit 데모 전후 비교; Chromium CDP 실제 일시정지/재개 시험; 최종 배포 파일 해시·공개 경로·브라우저 재확인. CDP는 테스트 도구이며 SDK 기능이 아니다.
