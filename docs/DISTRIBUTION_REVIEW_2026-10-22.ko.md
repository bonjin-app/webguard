구현 소스는 `1409d18`, CDN 초기화 예제의 캐시 복귀 보완은 `02a8f34`입니다. npm 게시는 보류했습니다. 기존 `.npm-release/` 후보와 기록, 전역 Codex 설정의 바이트를 유지했습니다.

## 적용한 동작

- 선택된 정적 HTML의 일반·모듈 인라인 스크립트를 각각 제자리에서 난독화합니다. 전역 바인딩·순서·속성을 유지하고 생성 보조 이름 충돌을 피합니다. JSON·import map의 데이터 텍스트를 유지하며 템플릿 속 스크립트의 비활성 상태도 실제 세 브라우저에서 확인했습니다.
- 최종 스크립트 텍스트의 SHA-384를 자동 소유 CSP 메타·HTTP 정책 파일에 반영한 뒤 외부 SRI·매니페스트를 생성합니다. 정적 출력 전체에서 공유하는 해시 허용 목록이며, 정책이 16 KiB를 넘으면 실패합니다. 기존 별도 소유 CSP를 몰래 변경하거나 `unsafe-inline`·`unsafe-eval`을 추가하지 않습니다.
- 감지한 동적 코드 문자열·미해결 JSP/PHP/Jinja 표현·정책 충돌은 위치가 있는 오류로 빌드를 중단합니다. 입력과 이전 출력은 보존하고 인라인 소스맵은 공개 경로 밖에 저장합니다. 감지기는 보수적인 구문 분석이며 임의의 별칭·런타임 데이터 흐름을 전부 증명하는 분석기가 아닙니다. 요청별 서버 템플릿과 Next Flight를 정적 HTML로 취급하지 마세요.
- 독립 SDK `.js`, 로컬 설치용 `.tgz`, 외부 초기화 예제와 라이선스를 직접 제공합니다. SDK CDN 파일 자체에도 High·RC4 난독화를 적용하고 공개 API를 보존합니다. CDN SDK는 런타임 가드용이며 앱 난독화는 빌드 도구로 적용합니다.
- SDK 연결 예제는 SRI·`crossorigin`·`defer`와 외부 초기화 순서를 제공합니다. 초기화 예제는 캐시되는 `pagehide`에서 인스턴스를 유지하고 실제 종료에서만 정리합니다. 단위 테스트와 실제 브라우저의 `persisted` 수명주기 이벤트로 검증했으며, 모든 기기의 실제 뒤로가기 캐시 적중을 인증한 결과는 아닙니다.
- 한국어 설치·환경별 가이드, 패키지 동봉 문서, 공개 HTML·텍스트 문서를 동기화했습니다. 같은 파란색 다운로드 UI를 데모와 문서에 연결하고 실패·재시도·모바일 배치를 검사했습니다.
