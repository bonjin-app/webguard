# WebGuard Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for integration; bounded independent package work may be delegated under the user's explicit routing instructions. Steps use checkbox syntax.

**Goal:** Deliver a runnable local open-source browser protection toolkit, tests, examples and playground.
**Architecture:** Shared typed policy drives an AST obfuscator and a transactional filesystem pipeline. The browser SDK has no automatic network collection. Vite transforms chunks before filenames are finalized, then protects deployment artifacts.
**Tech Stack:** Node 22+, pnpm, TypeScript strict ESM, tsup, Turbo, Vitest, Playwright, javascript-obfuscator, Vite, React.
**Spec:** ../specs/2026-10-20-webguard-design.md and ../../reference/original-brief.ko.md

## Global Constraints

- No Codex configuration changes, npm publication or external deployment.
- Standard preset; shortcut/context menu blocking opt-in; no debugger loops.
- Source input preserved; private maps outside public output; atomic output publication.
- Client detection and manifests are advisory unless anchored by trusted deployment verification.
- Tests and compatibility claims must reflect observed evidence.

## Review Focus

- Reject nested output/private-map paths and symlinks; preserve original on failure.
- Preserve ESM exports, dynamic imports, async and serialized property names.
- Reject manifest traversal and malformed entries; detect changed, missing and unexpected files.
- No keyboard blocking by default; deduplicate hints and clean up listeners.
- Playground untrusted code must have opaque origin, no network and a bounded lifetime.
