# 변경 기록

## 0.3.0 로컬 후보 — npm 게시 보류

현재 공개 npm 버전은 0.2.0입니다. 아래 내용은 최신 소스와 공개 데모의 미게시 후보 기준입니다. 보류 중인 배포 압축 파일을 최신 구현으로 간주하지 마세요.

- Vite 외에 Webpack·esbuild·정적 HTML용 보호 후처리와 Next App Router의 운영 클라이언트 청크 연동을 제공합니다. Java/JSP·Python·PHP는 보호한 외부 정적 파일과 서버 정책으로 연결합니다.
- 선택한 CSS Modules 식별자, 정적 DOM 변경 관찰, 실행 지연 관찰과 런타임 정책 변경을 데모에서 비교합니다. 개발자도구 열림·닫힘이나 브라우저 소스 비공개를 보장하지 않습니다.
- 최종 바이트의 SRI와 배포 해시를 확인하고, 공개 소스맵·원본 소스·백업 파일을 제외합니다. 이미 압축된 코드의 보호 누락은 빌드 실패로 처리합니다.
- Vite의 마지막 출력 경로 변경도 검사하며, Next에서는 서버·RSC 코드를 유지합니다. 기존 애플리케이션의 CSP·nonce 책임은 환경별 가이드에서 구분합니다.
- 입력 설정의 상속 값·접근자·희소 배열을 거부하여 난독화·무결성 기본값이 의도치 않게 약화되는 경로를 차단합니다.
- 한국어 설치·환경별·SSR 검증 안내를 같은 디자인의 읽기 가능한 문서로 제공합니다. 원본 텍스트 다운로드도 유지합니다.
- 동일한 임시 패키지를 새 프로젝트에 설치하는 검증을 CI에 추가합니다. 로컬 보류 후보를 재생성하거나 npm에 게시하지 않습니다.

## 0.2.0 — 2026-10-20

- `webguard-check` 명령과 Node 전용 `uulab-webguard/verify`를 추가했습니다. 신뢰된 로컬 빌드를 기준으로 배포 파일·실제 헤더·소스맵·보고서 노출을 함께 검사합니다. 실패 시 종료 코드 1을 반환합니다.
- 원격 검사는 요청별 제한 시간과 스트림 해시를 사용합니다. 기대 크기를 넘으면 다운로드를 중단하고 네트워크 실패를 항목별로 보고합니다. 경로 검증은 네트워크 요청 전에 수행합니다.
- Shadow DOM의 편집 영역에서 단축키·우클릭을 가로채지 않습니다. SDK 종료와 무결성 기능 비활성화 시 진행 중인 요청을 취소합니다.
- Vite의 보호 후처리 경로와 다른 출력 위치를 지정하는 설정을 거부합니다.
- npm 게시 성공 후 레지스트리 반영 지연을 제한적으로 기다립니다. 게시 자체를 반복하거나 기존 버전을 덮어쓰지 않습니다.
- 한국어 가이드와 실제 설치 소비자 검증에 배포 검사 명령을 포함했습니다.

기존 `webguardApp()` 설정을 그대로 사용할 수 있습니다. 별도 Rollup/Rolldown 출력 설정을 사용했다면 `build.outDir`로 통합하세요. 난독화는 분석 비용을 높이는 기능이며 서버의 인증·권한 검사를 대체하지 않습니다.
