- Strict TypeScript monorepo, typed presets and output-path selection.
- AST-based JavaScript protection, private-map options and transactional CLI.
- SHA-384 manifest verification, HTML SRI integration and optional deployed URL checks.
- Build-only Vite plugin and event-driven browser SDK with cleanup.
- Vanilla JS/TS, React/Vite, JSP/Servlet examples and local Playground.
- Unit/integration/browser tests, local documentation and CI preparation.
- Stronger Strict/High transforms with default RC4 string encoding, function wrappers, string splitting and numeric expressions.
- Validated CSP/Trusted Types response-header API and `headers` CLI command, with browser attack regression tests.

- Opt-in `webguardApp()` combines Strict protection, automatic SDK injection and server header artifacts in one Vite configuration.
- Live SDK policy updates and a runnable Node response-header server example.

- Runnable example hub with one-click High samples, live SDK trials, copyable integration snippets and same-origin protected applications via `pnpm demo`.
